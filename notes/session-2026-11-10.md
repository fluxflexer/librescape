## What was built

### 1. Sources
- Table `source` (`sql/01_schema.sql`): unique `code`, `source_type` book / newspaper / wikipedia, title, author (+ optional `author_person_id`), editor, published date + precision.
  - Book: publisher, place, ISBN. Newspaper: newspaper, page. Wikipedia: language, accessed date.
  - Common: `url`, `wikipedia_url` (article about the book/newspaper), `publication_id`, notes.
  - CHECK constraints: books need author, date, publisher, and an ISBN if published 1970 or later; newspapers need name and date; Wikipedia needs url, language, accessed date.
- Table `source_ref` links sources to person / event / period / publication, with optional `locator` and `note`.
- Rule: every entry needs at least one source (period start/end markers exempt). `tools/check_sources.php` lists violations; `deploy.ps1` runs it and warns.
- Seed: `sql/03_sources_tolkien.sql` – books CARP, LETT, GARTH, HOB, FOTR, TT, ROTK, SIL; obituaries NYT-1973-09-03, TIMES-1973-09-03; Wikipedia sources W-* (ids 40–77).
- UI: "Sources" section in the detail panel with code badges; clicking opens the source with facts and a "Cited by" list; a red note shows when an entry has no source. Search finds sources by code, title, author, newspaper.

### 2. Weblinks
- Table `weblink` (entity_type, entity_id, link_type wikipedia/website/cv/archive/other, optional label, url, sort_order) – any number per entry.
- Old `wikipedia_url` / `cv_url` columns removed from person, event, period, publication.
- Shown as a "Links" section before "Sources". The image fetcher uses the first Wikipedia weblink.

### 3. Keyword lanes
- Dropdown "keyword" in the top bar; keyword chips in the detail panel.
- Each selected keyword adds a "# keyword" lane on top (several at once, newest on top) with copies of all tagged items in their original colours. Close via × on the lane, the dropdown (✓ marks open lanes) or the chip.

### 4. Layout
- In every lane, periods sit above events/works (vis-timeline subgroups with `subgroupStack` and `subgroupOrder`).

### 5. Data additions
- Vietnam War (period 17, World events, keyword war): Gulf of Tonkin incident (2 Aug 1964, start marker with description, image, link, source W-TONKIN) to Fall of Saigon (30 Apr 1975).
- Coronation of Elizabeth II (event 61, 2 Jun 1953) with new keyword "monarchy" (also on Victoria's death).
